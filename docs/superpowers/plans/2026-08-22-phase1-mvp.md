# Phase 1 MVP Implementation Plan

> For agentic workers: Use superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** Bootstrap Phase 1 MVP of a Microsoft To Do-inspired task manager.

**Architecture:** Feature-first Clean Architecture, stream-through ObjectBox repos, thin per-view BLoCs, fpdart Either error handling.

**Spec:** Approved Phase 1 design (brainstorming conversation).

## Global Constraints

- Platforms: Android, iOS, Windows, macOS, Linux (no web)
- Domain imports only Dart SDK, equatable, fpdart
- IDs: String UUIDs; ObjectBox dbId never exposed
- All repo returns: Either<Failure, T> / Stream<Either<Failure, T>>
- Sealed Failure: CacheFailure, ValidationFailure, NotFoundFailure
- Reactive streams only, no manual refresh
- TDD: use cases, repos, blocs, one widget test
- Default list "Tasks" seeded on first launch
- Haptics on completion toggle + swipes

## Tasks

1. **Dependencies & tooling** - pubspec.yaml + pub get + analyze
2. **Core failures** - sealed Failure hierarchy + tests
3. **Task entity** - domain entity + copyWith + isOverdue + tests
4. **TodoList + ListSummary entities** - domain entities + tests
5. **Task contracts + use cases** - repository interface + 6 use cases + mocktail tests
6. **List contracts + use cases** - repository interface + 4 use cases + tests
7. **ObjectBox models** - TaskModel, TodoListModel + codegen + mapper tests
8. **TaskRepositoryImpl** - reactive impl + integration tests
9. **TodoListRepositoryImpl** - dual-watch counts + cascade delete + tests
10. **DI + entrypoint** - injectable module, main.dart, bootstrap, smoke run
11. **Theme + router + shell** - Material 3, go_router, adaptive navigation
12. **MyDayBloc** - bloc events/states + bloc_test suite
13. **My Day UI** - polished page, task tile, completion checkbox, quick add + widget test
14. **Lists overview + detail** - ListsBloc, ListDetailPage, TaskListBloc
15. **Verification** - flutter analyze, full test suite, smoke checklist
